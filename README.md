# noufilnaveed.com

Personal portfolio of Noufil Naveed, backend developer. One page built with Next.js and Tailwind CSS, hosted on Hostinger.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Edit content

Projects, skills and contact links live at the top of `src/app/page.js`.

## Deploy

Pushing to `main` on GitHub redeploys the site on Hostinger.
